# ShortForge 베타 가이드

"무엇을 말하고 싶은지"만 입력하면, 잘 된 숏폼의 구조를 분석해 내 소재로 30초 영상(MP4와 자막)을 만든다. 모든 단계를 무료 도구로만 돌리며, 사용자 PC에서 실행한다.

## 1. 준비물 (Windows 10/11)

| 항목 | 설치 |
|---|---|
| uv (Python 관리) | `winget install astral-sh.uv` |
| Node.js 20.9 이상 | `winget install OpenJS.NodeJS.LTS` |
| FFmpeg | `winget install Gyan.FFmpeg` |
| 디스크 | 10GB 이상 여유 |

GPU는 필요 없다. 장면 이미지는 **본인 사진**을 쓴다(장면 수보다 적으면 돌려 가며 쓴다).

**(선택) 무료 이미지 자동 채우기:** 사진이 부족한 장면을 무료 서비스로 채울 수 있다.
- **Cloudflare 무료 AI 생성:** 카드 등록 없이 하루 약 64장. dash.cloudflare.com에서 계정 ID를 복사하고, 내 프로필 → API 토큰 → "Workers AI" 템플릿으로 토큰을 만든다.
- **Pixabay 무료 사진:** pixabay.com에 무료로 가입하고 로그인한 뒤 pixabay.com/api/docs/ 의 "Parameters" 표에서 `key` 값을 복사한다.
- 설정 화면에서 이미지 방식을 "AI 생성 → 무료 사진"으로 고르고 Cloudflare 계정 ID·토큰과 Pixabay 키를 넣는다(`.env`에서 `IMAGE_MODE=cloudflare,stock`으로 바꿔도 같다). 5단계 장면 카드에 출처(본인 사진/AI 생성/무료 사진)가 표시되고, "다른 이미지"로 장면 하나만 다시 만들 수 있다.

## 2. API 키 2개 (무료)

1. **YouTube Data API v3**: Google Cloud Console에서 프로젝트를 만들고 "YouTube Data API v3"를 사용 설정한 뒤, 사용자 인증 정보에서 API 키를 만든다.
2. **Gemini**: https://aistudio.google.com/apikey
   - ⚠️ **결제(billing)가 연결되지 않은 프로젝트**에서 키를 만든다. 결제가 연결되면 유료 등급이 되어 호출마다 과금된다.
   - 무료 등급에서는 입력 내용이 Google의 모델 개선에 쓰일 수 있다. 민감한 내용은 넣지 않는다.

## 3. 설치와 실행

1. `shortforge\setup.bat`을 더블클릭한다(처음 한 번, 몇 분 걸림). `shortforge\.env` 파일이 만들어진다.
2. `shortforge\start.bat`을 더블클릭하면 브라우저에 http://127.0.0.1:3000 이 열린다. 끝낼 때는 창을 닫는다.
3. 홈 오른쪽 위 **설정 (API 키)**에서 두 키를 붙여 넣고 "확인하고 저장"을 누른다. 키마다 ✓/✕와 이유가 나오고, 확인을 통과한 키만 `shortforge\.env`에 저장된다. 다시 시작할 필요는 없다.
   - 결제가 연결된 Gemini 키는 저장하지 않는다(과금 방지).
   - `.env`를 직접 고쳐도 된다. 그때는 `start.bat`을 닫았다가 다시 실행한다.
   - 무료 이미지(Pixabay·Cloudflare)를 쓰려면 같은 화면에서 이미지 방식을 고르고 그 키를 넣는다.

## 4. 첫 영상 만들기 (약 15분)

| 단계 | 할 일 | 팁 |
|---|---|---|
| 1. 개인 입력 | 주제·타깃·톤·길이를 입력하고, 본인 사진 3~7장을 올린다(무료 이미지를 설정했다면 없어도 된다) | 주제는 구체적으로 쓴다. 예: "퇴근 후 10분 홈트로 3개월간 바뀐 점" |
| 2. 레퍼런스 탐색 | "여기서부터 끝까지 실행"을 누르거나 단계별로 실행한다 | ✗ 표시는 주제와 관련이 낮은 영상이다. 체크박스로 분석할 영상을 바꿀 수 있다 |
| 3. 성공 요인 | 근거와 "확인/추정" 표시를 본다 | "추정"은 메타데이터로 직접 확인할 수 없는 요인이다. 썸네일 근거는 Gemini가 썸네일을 보고 쓴 관찰이다 |
| 4. 제작 전략 | 장면 대사와 제목 A/B를 고치고, 장면 카드를 끌어서(또는 ▲▼) 순서를 바꾼다 | 고치면 5~7단계에 "재생성 필요"가 붙는다. 첫 장면은 훅으로 둔다 |
| 5. 자산 생성 | 장면별 사진·음성을 확인하고, 필요하면 "사진 교체"를 한다. 다시 실행해도 장면 묘사가 그대로인 장면의 이미지는 유지된다 | 무료 이미지를 설정했다면 "다른 이미지"나 "후보 3개"로 고른다. 아니면 "이미지 프롬프트 내보내기"로 외부에서 만든 뒤 올린다 |
| 6. 편집 지시서 | "미리보기 재생"으로 장면 이미지·음성·모션·배경음악을 이어 본다. 배경음악 패널에서 분위기를 바꾸거나 내 음악을 올린다 | 렌더 전에 흐름을 확인한다. 미리보기에서는 목소리가 나올 때 음악이 작아지지 않는다(렌더에서 처리) |
| 7. 렌더 | MP4와 SRT를 다운로드하고 "업로드 전 체크리스트"를 확인한다 | 설명란 문구(AI 사용 고지·사진 출처·해시태그)를 복사해 쓴다. "A/B 버전 만들기"로 대사만 바꾼 변형을 만든다 |

## 5. 알려진 한계

- **이미지 생성:** 기본값(`IMAGE_MODE=upload`)은 본인 사진만 쓴다. Cloudflare 무료 생성은 하루 약 64장이며, 넘으면 Pixabay 사진으로 채운다.
- **음성:** Edge-TTS(무료, 비공식 엔드포인트)를 쓴다. 상업적 이용 조건은 불명확하다.
- **분석:** YouTube API는 다른 채널의 시청 지속률을 주지 않는다. 훅·화면 구성 요인은 "추정"이다.
- **쿼터:** 2단계(레퍼런스 탐색)는 하루 약 19번까지 실행할 수 있다(1번에 약 410 units, 하루 8,000 units에서 차단, 태평양 시간 자정에 초기화). 같은 날 같은 키워드는 캐시를 써서 쿼터를 쓰지 않는다.
- **Gemini 무료 한도:** 주 모델은 하루 20회다. 한도나 서버 과부하 때는 경량 모델로 대신 처리하고 경고를 띄운다(품질이 낮을 수 있다).
- **고급 모드 (선택, 유료):** 설정 화면에서 본인 Anthropic·OpenAI·OpenRouter 키로 켜면 3·4단계만 유료 모델이 맡아 무료 한도와 과부하의 영향을 덜 받는다. **본인 계정에 비용이 청구된다.** 하루 예산을 정할 수 있고, 넘으면 무료로 돌아간다. 베타 테스트에는 필요 없다.
- **업로드 전:** 7단계 체크리스트는 안내일 뿐이다. 최신 AI 콘텐츠 고지 정책은 YouTube 업로드 화면에서 확인한다.
- **되돌리기:** 오른쪽 패널 "버전 기록"에서 이전 버전으로 되돌릴 수 있다. 5~7단계는 다시 만들어야 할 수 있다.

## 6. 데이터와 피드백

- 모든 데이터는 `shortforge\data\` 폴더(내 PC)에만 저장된다.
- 사용 통계는 `shortforge\data\metrics.jsonl`에 남는다. 프로젝트 ID·단계·시간만 기록하고 주제나 대사는 기록하지 않는다. **원할 때만** 이 파일을 공유해 준다.
- 매주 `docs/BETA_FEEDBACK.md` 설문에 답해 준다.
- 오류가 나면 홈 화면 아래(또는 작업 화면 오른쪽 "관리")의 **문제 보고용 파일**을 받아 함께 보내 준다. 로그·환경 정보·사용 통계가 들어 있고 API 키는 들어가지 않는다. 작업 화면에서 받으면 그 프로젝트의 주제·대사도 들어가니 열어 보고 보낸다.
- 디스크가 차면 작업 화면 오른쪽 "안 쓰는 파일 정리"나 홈 목록의 "삭제"를 쓴다.
