# ShortForge 작업 대화 기록 (2026-10-15 ~ 2026-10-26)

Claude Code와 함께 ShortForge를 개발한 대화를 요청 순서대로 정리한 기록이다. 대화를 그대로 옮긴 것이 아니라, 요청마다 무엇을 했고 결과와 결정이 무엇이었는지를 남겼다. 커밋 해시와 릴리스는 GitHub 공개 저장소 `awesome72/shortforge` 기준이다.

- 프로젝트: 주제·타깃을 넣으면 YouTube 레퍼런스를 분석해 30초 세로 숏폼(MP4 + SRT)을 만드는 7단계 파이프라인. 기본 경로는 비용 ₩0이다.
- 개발 PC: GPU 없음, RAM 8GB, i5-8265U.
- 계속 지킨 원칙:
  - 기본 경로 ₩0. 유료 LLM은 선택형 고급 모드에서만 쓴다.
  - 레퍼런스 영상은 내려받지 않는다.
  - 키는 화면이나 로그에 내보내지 않는다.
  - 공개 저장소에 `.env`·`data/`를 커밋하지 않는다.
  - 서버는 확인이 끝나면 끈다.
  - 응답은 한국어로 한다.

## 4. 확정된 결정과 근거

- **D13 고급 모드**: 끄면 ₩0, 켤 때는 키와 동의가 필요하고 하루 예산 안에서만 쓴다. 3·4단계에만 유료 모델을 쓴다. 추천은 Sonnet 5.5.
- **D14 배경음악**: 로컬 합성. 음원 API는 라이선스·키·GPU 문제로 보류했다.
- **글꼴**: 저장소에 넣지 않고 PC에 있는 것을 고른다(Pretendard → Noto Sans KR → 나눔고딕 → 맑은 고딕).
- **보정 위치**: 무거운 색 보정은 병렬·캐시되는 클립 단계, 그레인과 페이드만 합성 단계.
- **대사 분량**: 짧으면 경량 모델로 보강하고, 주 모델 재생성은 하지 않는다(무료 한도 보호).

## 5. 남은 일과 주의

- 3단계 음원 라이브러리(Freesound)는 사용자 키가 필요해 보류했다.
- 오래된 테스트 프로젝트 정리는 지우면 되돌릴 수 없어 사용자 확인 뒤에 한다.
- 실제 파이프라인을 실행하기 전에는 고급 모드(유료)가 켜져 있는지 확인한다.
- 렌더가 느릴 때는 다른 프로그램의 CPU 사용을 먼저 확인한다.
- 기존 프로젝트에 새 품질을 적용하려면:
  - 7단계만 다시 렌더하면 자막, 색 보정, 엔딩 카드가 들어간다.
  - 5단계부터 다시 실행하면 목소리, 음악, 그림 규칙까지 들어간다.
