# ShortForge 베타 운영 안내 (모집 → 배포 → 수집 → 판정)

베타의 목적은 **M2 Gate 판정**이다(PRD §10, PROJECT_PLAN). 테스터 10명이 2주 동안 영상을 만들고, 그 기록으로 다음을 정한다.

| 판정할 것 | 기준 (PRD §10 "기준" 시나리오) | 데이터 |
|---|---|---|
| 완주율 | 40% 이상 (프로젝트 생성 → MP4 다운로드) | 문제 보고 파일 |
| 1편 제작 시간 | 중앙값 15분 이하 | 문제 보고 파일 + 설문 A-2 |
| 재생성 비율 | 25% 안팎 | 문제 보고 파일 |
| 레퍼런스 점수 가중치 (PRD 미결 4) | 기본 선택을 바꾼 비율과 이유 | 설문 C |
| 유료 플랜의 가치 (D5) | 쓰고 싶은 유료 기능 | 설문 E |

## 1. 모집

- **인원:** 10명 (PRD M1 목표)
- **대상:** 숏폼을 만들어 보고 싶거나 이미 만드는 사람. 1인 크리에이터, 소상공인, 직장인 부업 등. 영상 편집 경험은 없어도 된다.
- **필요한 것:**
  - Windows 10/11 PC (RAM 8GB 이상, GPU 필요 없음)
  - Google 계정 (YouTube·Gemini 키를 무료로 받는다. 결제 수단 등록 필요 없음)
  - 2주 동안 영상 3편 이상과 설문 5분씩
- **비용:** 없음. 고급 모드(유료)는 베타에 필요 없으니 켜지 않도록 안내한다.

### 모집 글 (붙여넣기용)

> **[베타 모집] 잘 된 숏폼의 구조로 내 30초 영상을 만드는 무료 도구, ShortForge**
>
> 주제와 타깃을 넣으면 최근 잘 된 YouTube 숏폼을 찾아 "왜 잘 됐는지"를 근거와 함께 정리하고, 그 구조로 30초 세로 영상(MP4 + 자막)을 만들어 줍니다. 대본, 음성, 자막, 이미지까지 한 화면에서 끝나고 비용은 들지 않습니다.
>
> - 기간: 2주 / 영상 3편 이상 만들고 편당 5분 설문
> - 준비물: Windows PC, Google 계정 (API 키는 무료, 안내서대로 10분)
> - 드리는 것: 정식 버전 우선 사용, 피드백 반영 결과 공유
>
> 신청: (연락처 또는 신청 양식 링크)

## 2. 배포

저장소가 **공개**라 테스터가 릴리스 페이지에서 직접 받을 수 있다(GitHub 계정 필요 없음).

- 릴리스 페이지: https://github.com/awesome72/shortforge/releases — 가장 최근 사전 배포판(`v0.3.0-beta.10` 이상)의 "Source code (zip)"을 받는다.
- 링크만 보내도 되고, zip을 받아 직접 전달해도 된다.

함께 보낼 것: [`BETA_GUIDE.md`](BETA_GUIDE.md) (설치와 첫 영상), [`BETA_FEEDBACK.md`](BETA_FEEDBACK.md) (설문)

## 3. 테스터가 돌려줄 것

| 언제 | 무엇 | 방법 |
|---|---|---|
| 영상 1편마다 | 설문 | `BETA_FEEDBACK.md` 양식 |
| 매주 금요일 (2회) | **문제 보고 파일** | 홈 화면 아래 "문제 보고용 파일"을 눌러 받은 zip의 **이름을 본인 이름으로 바꿔**(예: `kim.zip`) 보낸다 |
| 문제가 생겼을 때 | 문제 보고 파일 + 무엇을 하다가 생겼는지 | 프로젝트 화면 오른쪽 "관리"의 문제 보고 파일(그 프로젝트 파일이 함께 들어간다) |

**홈 화면의 문제 보고 파일에 들어가는 것:** 로그, 환경 정보, 사용 통계(프로젝트 ID·단계·시간). API 키는 지워져 있고 주제·대사는 들어 있지 않다. 프로젝트 화면에서 받은 파일에는 그 프로젝트의 주제·대사가 들어간다는 점을 테스터에게 알린다.

## 4. 집계와 판정 (운영자)

받은 zip을 한 폴더에 모아 실행한다(`shortforge/backend`에서).

```bash
uv run python ../scripts/kpi_report.py 받은파일/*.zip
```

- 테스터별 프로젝트·완주 수, KPI 표(완주율, 제작 시간, 재생성 비율, 근거 커버리지, 쿼터)와 판정(비관 미달 ~ 낙관 달성), 주간 완주 수, LLM 속도 표가 나온다.
- 같은 사람이 같은 파일을 두 번 보내도 한 번만 센다. 2주차 파일에는 1주차 기록이 포함되므로 **2주차 파일만으로도 충분하다**.
- 판정 결과와 설문 요약은 `PROJECT_PLAN.md`의 M2 Gate 항목에 기록한다. 기준에 못 미치는 지표는 설문의 "멈춘 단계와 이유"로 원인을 찾는다.
